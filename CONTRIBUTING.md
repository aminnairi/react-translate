# Contributing to @aminnairi/react-translate

First off, thank you for considering contributing to `@aminnairi/react-translate`! We welcome all contributions, whether it's reporting a bug, proposing a new feature, or submitting a pull request.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/your-username/react-translate.git`
3. **Install dependencies** at the root of the project: `npm install`
4. **Create a new branch** for your feature or bug fix: `git checkout -b feature/my-new-feature`

## Submitting a Pull Request

1. Make your changes in your branch.
2. Ensure your code follows the existing style and conventions.
3. Commit your changes with clear, descriptive commit messages.
4. Push to your fork: `git push origin feature/my-new-feature`
5. Open a Pull Request against the `main` branch of the original repository.

## Bug Reports and Feature Requests

Please use the [GitHub Issues](https://github.com/aminnairi/react-translate/issues) tracker to report bugs or suggest new features. Include as much detail as possible (such as code snippets, error logs, and expected behavior) to help us understand and resolve the issue quickly.
